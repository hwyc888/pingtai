1. 服务设置

学校统一身份认证 (OAuth2)

填写学校提供的 client_id、client_secret 和在统一身份认证平台注册的完整回调地址。管理员账号使用学校统一认证的账号标识，多个账号用苯号、分号或换行分隔。

2. SQLite 数据库

系统会自动创建 SQLite 数据库文件。无需安装 MySQL。请在上方指定数据库文件路径，确保运行用户有读写权限。

3. 本地管理员（仅旧登录模式使用）

仅在不启用学校 SSO 的旧模式需要初始管理员。启用 SSO 后，管理员权限由上方的 SSO 管理员账号白名单控制。

4. OpenAI 兼容接口

Base URL 可填 https://api.openai.com/v1 或其他兼容服务的基础地址，也可填完整 /chat/completions 地址。本地无认证服务可留空 API Key。模型能力取决于上游。

OpenAI 模型获取与多选

先填上方 Base URL 和 API Key，再获取模型。勾选的模型会显示在聊天页的模型/智能体选择列表。这是可切换的多个模型，不是一次向多个模型同时提问。

获取不会保存配置，也不需要先连接数据库。勾选后请在上方选择默认模型，然后保存并重启。获取失败可手动添加。
